# first- Clone it in your local
git clone git@github.com:ashishrajbanshi/xv6-riscv-boot.git

# Create your own branch 
git branch your_name


Now, our main branch name is riscv. So, everyone on their branch can push their changes in riscv.

# How to push

1.
Try this when you want to push all the changes done in your branch

git add .

Or 

<file_name> are name of file that you want to push
git add <file_name>


2.
git commit -m "What changes did you make"

3.
git push
